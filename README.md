# X-Auto-Tweet-Tool (X 自動操縦・自動ツイートボット 最新版)

X (旧Twitter) のブラウザ自動操縦・自動ツイート・複数アカウント運用システムです。  
Web UI 管理画面（React SPA）と、Windowsデスクトップ用自動操縦ボット（Python / Playwright / PyInstaller EXE）の完全統合プロジェクトです。

---

## 🌟 主な機能と特徴

1. **【提案1】1窓・順番交代ローテーション**
   - 複数アカウントを運用する際、常時起動するブラウザは**常に1つだけ**。
   - 1アカウントの投稿が終わるとブラウザを完全終了してメモリを全解放。低スペックPCでもクラッシュせず安定動作します。

2. **【提案2】画像・動画通信遮断フィルター**
   - タイムライン読み込み時の高画質動画・画像を通信段階でブロックし、メモリを約60%削減＆高速動作。

3. **【案3: 新機能】画像クールダウン＆アカウント間重複防止（凍結対策）**
   - **14日間クールダウン**: 一度使った画像は最低14日間は再選出されません。
   - **7日間クロスアカウントロック**: 「アカウント①が使った画像は、アカウント②は今週使わない」共有ロック。同一IPからの画像重複によるシャドウバン・凍結リスクを徹底防止します。
   - `image_cooldown_history.json` で選出履歴を永続管理。

4. **日常ツイート独立エンジン（朝枠・昼枠・夕方枠・夜枠）**
   - 時間帯（7:00-9:00, 11:30-13:30, 17:00-19:00, 20:00-23:30）に合わせた日常ツイートを自動投稿。
   - 30日間重複なしの安全運用。

5. **スピンタックス記法 `{A|B|C}` ＆ リアルタイム動的置換**
   - `{月日}` `{曜日}` `{時間}` `{日付}` などのリアルタイム動的差し込みに対応。

6. **凍結アカウントの即時永久除外（再起動不要）**
   - アカウントの凍結や制限を検知した場合、即時にメモリから除外し、残りの健全アカウントで完全自動継続します。

7. **重複エラー自動リトライ（絵文字付与）**
   - X側で重複投稿エラーが検知された場合、自動で末尾にランダム絵文字を添えてリトライ送信。

## 📁 フォルダ・ファイル構成

- `auto_tweet_playwright.py`: 自動操縦ボット本体のPythonコード（最新版）
- `add_daily_tweets_excel.py`: Excelファイルに「日常ツイート」シートを自動生成するスクリプト
- `update.ps1`: ワンクリックで最新EXEのビルドと配布フォルダへの上書きを行うPowerShellスクリプト
- `START_ROTATION.bat`: ボット起動用バッチファイル
- `src/`: Web UI管理画面（React + TypeScript + Vite）のソースコード
- `images/`: 画像保存フォルダ（`朝枠/`, `昼枠/`, `夕方枠/`, `夜枠/`）

---

## 🚀 使い方

### 1. Windows PCでのワンクリックアップデート（update.ps1）
PowerShellで以下のコマンドを実行するだけで、自動で最新EXEがビルドされ、配布用フォルダへ反映されます：
```powershell
.\update.ps1
```

### 2. ボットの起動
`START_ROTATION.bat` をダブルクリックするか、配布用フォルダ内の `X_AutoTweetBot.exe` を実行します。

### 3. Web UI 管理画面の起動（開発・シミュレーション用）
```bash
npm install
npm run dev
```
ブラウザで `http://localhost:3000` を開きます。
